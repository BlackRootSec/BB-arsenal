# BB-arsenal-
bb-arsenal: a one-command installer for bug bounty and recon workstations, written in Go with zero dependencies. Installs 99 tools (subfinder, nuclei, httpx, ffuf, amass, sqlmap, dalfox and more) via go, apt, pipx, cargo and npm, skips what's already installed, handles Debian's pip restrictions, logs every install, with an animated terminal UI.
